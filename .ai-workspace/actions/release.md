# RELEASE

מטרה: להכין checkpoint או release proposal ללא פרסום.

1. ודא Definition of Done ו־full gates.
2. הצג branch, HEAD, remote, dirty state ו־diff stat.
3. סכם behavior, migrations ידניות נדרשות, rollback ו־known limitations.
4. הצע commit message תיאורי וספציפי.
5. השתמש ב־[`../playbooks/release-flow.md`](../playbooks/release-flow.md).

אין commit, push, deployment או migration מתוך פעולה זו.

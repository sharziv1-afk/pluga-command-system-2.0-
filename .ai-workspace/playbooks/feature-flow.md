# Feature Flow

1. PLAN: problem, users, acceptance criteria ו־out-of-scope.
2. DESIGN כאשר יש UI/API contract חדש.
3. IMPLEMENT slice אנכי קטן לפי patterns קיימים.
4. QA happy path, states, permissions ו־regression.
5. REVIEW ואז HANDOFF.

שינוי DB עובר בנפרד דרך [`database-change-flow.md`](database-change-flow.md).

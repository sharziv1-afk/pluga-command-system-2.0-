# Release Flow

1. ודא scope סגור ו־Definition of Done.
2. הרץ full preflight ובדיקות browser רלוונטיות.
3. REVIEW אבטחה/ביצועים לפי סיכון.
4. תעד Git state, migrations ידניות, rollback ו־known limitations.
5. הכן handoff ו־commit proposal.

עצור לפני commit, push או deployment והמתן להוראה מפורשת.
